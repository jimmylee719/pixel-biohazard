# 系列設定集（Series Bible）

> 狀態：草稿 v0.1，系列名稱與長線劇情等待確認
> 用途：讓 1～6 代以及之後的外傳，共用同一套世界觀、時間軸和規則。每一代開發前都要先回來看這份文件。

---

## 1. 系列名稱

### 1.1 選名標準
一個能用幾十年的系列名稱，要做到下面幾件事：

| 標準 | 說明 | 反例 |
|---|---|---|
| **不綁在第一代的場景上** | 2 代以後會換地點（深海、高原、南極），名字不能只講「冰」或「北極」 | 《凍鳴》、*THAWED*、*PERMAFROST ECHO* 都太綁第一代 |
| **講的是整個系列的核心概念** | 本系列的核心是「沉睡在遠古的生命，因為地球變暖而醒來」 | |
| **加上數字和副標題還是好念** | 「XX 2」「XX 3：副標題」要順口 | |
| **中英文各有一個好記的名字** | 參考惡靈古堡在不同市場用 *Resident Evil* / *Biohazard* 兩個名字，各自都成立 | |
| **搜得到、註冊得了** | 常見單字（例如 *Dormant*）搜尋時會被淹沒，也很難註冊商標；自創字比較能擁有 | |

### 1.2 候選名稱比較

| 候選 | 中文 | 意義 | 優點 | 缺點 | 初步搜尋結果 |
|---|---|---|---|---|---|
| **DEEPWAKE** | **《驚蟄》** | 英文：「深時（deep time，地質學說的億萬年尺度）」＋「甦醒」。中文：二十四節氣，冬眠的生物被春雷驚醒 | 自創英文字，好搜尋、好註冊；中文有東方文化根源，和歐美作品區隔明顯；完全不綁定場景 | 「驚蟄」是一般詞彙，中文商標要另外查 | 英文沒找到同名遊戲；中文沒找到同名的 Steam 遊戲 |
| **DORMANT** | 《沉眠》 | 休眠 | 直白、好懂 | 常見英文單字，搜尋和商標都很難；itch.io 上已經有一款叫 *Dormant* 的科幻恐怖遊戲 | 有撞名 |
| **STRATA** | 《地層》 | 每一代都是挖到更深的一層 | 系列感強，每代都能說「新的一層」 | 恐怖感比較弱，而且是常見單字 | 沒找到同名的恐怖遊戲，但詞太普通 |
| *LAZARUS* | 《復生》 | 「拉撒路分類群」：被以為滅絕、又重新出現的物種 | 概念很貼切 | Lazarus 在遊戲和影視作品裡已經被用爛了 | 很多作品使用 |
| *CRYPTOBIOSIS* | 《隱生》 | 生物學上的「隱生」狀態（例如水熊蟲） | 科學感強 | 已經有兩款遊戲用了這個名字 | 撞名 |

### 1.3 推薦：英文 **DEEPWAKE**／中文 **《驚蟄》**

```
DEEPWAKE                       驚蟄
DEEPWAKE 2: [副標題]            驚蟄 2：[副標題]
DEEPWAKE: Origins（前傳）        驚蟄 前傳：[副標題]
```

- **英文**：*Deep time* 是地質學概念，指人類無法想像的漫長時間尺度。*Deepwake* 就是「從深時中醒來的東西」，正好是整個系列在講的事。字很短，念起來有重量，數字接在後面也順。
- **中文**：「驚蟄」是二十四節氣之一，意思是蟄伏在土裡過冬的生物被春雷驚醒。用在這個系列裡就是：地球變暖，沉睡的遠古生命被驚醒。華語圈玩家一看就懂，對海外玩家則是很有記憶點的東方元素。
- 英文和中文意思一致，但各自都能獨立成立，和惡靈古堡在不同市場用不同名稱的做法一樣。
- **第一代**的完整名稱建議：*DEEPWAKE*／《驚蟄》，不加副標題，讓第一代就是系列的原點。

> ⚠️ **注意**：上面只是快速的網路搜尋，**不能當作商標檢索**。正式定案前，要到台灣智慧財產局、美國 USPTO、歐盟 EUIPO、日本特許廳查「電子遊戲」相關類別（第 9 類、第 41 類），最好請商標律師確認，同時檢查網域名稱和 Steam 頁面名稱能不能用。

## 2. 系列核心概念

> **地球在變暖。冰層、凍土、深海、冰河底下，封著數萬年前的生命。它們不是死了，只是在等。**

每一代都是同一件事在地球的不同盡頭發生：某個人類很少到的地方解凍了，某種遠古生命醒了過來，而有一群人早就知道。

### 2.1 系列不變的規則（每一代都要遵守）
1. **怪物一定有生物學的成因**：遠古微生物、遠古寄生生物，或它們造成的突變。不用魔法、外星人或鬼怪。
2. **沒有製藥公司或企業陰謀**：幕後黑手是一個跨國的秘密協定（見第 3 節），動機是「控制」和「長生」，不是賺錢。
3. **不是真菌、不是殭屍病毒**：每一代的病原體都屬於同一個虛構的古老譜系（見 2.2），各有不同的特性。
4. **每一代都在「地球的盡頭」**：極地、深海、高原、冰河底，人類很少到、救援進不來的地方。
5. **每一代都要把一個感知或環境要素變成玩法**：1 代是聲音、2 代是光、3 代是寒冷……讓每一代的潛行玩法都有新鮮感。
6. **每一代的故事都能獨立看懂**，但會留下線索連到更大的故事。

### 2.2 遠古生命的設定：「眠系」
- 研究者後來發現，世界各地挖出來的遠古微生物，其實**全部來自同一個極古老的譜系**，學界代號 **眠系（Hypnota，自創學名）**。
- 共通特性：
  - 在極端環境下能**休眠數萬年**（低溫、高壓、無光）。
  - 甦醒的條件和**溫度上升**有關。
  - 感染宿主後，宿主都會出現**某種「共鳴」**：1 代是喀喀聲，之後每一代以不同形式出現（光、熱、電訊號）。
- **系列最大的謎（長線）**：地球歷史上幾次大滅絕，都發生在暖化時期。眠系每次都在那時候大量甦醒。它不是意外，而是地球上一種極古老的「循環」。現在，人類親手讓地球變暖了。

### 2.3 為什麼「宿主會休眠」很重要
- 眠系能讓宿主在極低溫中「暫停生命」而不死亡。
- 這讓它成為某些人眼中的**長生不老之鑰**：如果能控制它，人就能「休眠」、等待未來的醫療。
- 這就是反派的動機，也是系列能一直延伸的引擎。

## 3. 貫穿系列的組織：「靜默協定」

### 3.1 起源（真實歷史錨點）
- **1957～58 年「國際地球物理年」**是真實歷史事件，各國在南北極大量設站、鑽冰芯。這是系列故事的起點。
- 在虛構的設定中：當年有幾支極地探勘隊挖到了「不該存在的活體」。幾個國家秘密簽下**《靜默協定》（The Quiet Accord）**：發現遠古生物樣本的國家，必須把樣本交給協定、並且對外保密。
- 協定的本意是**隔離和隱藏**，避免恐慌，也避免被做成武器。

### 3.2 分裂
經過幾十年，協定內部分裂成兩派：

| 派系 | 立場 | 在系列中的角色 |
|---|---|---|
| **守門派** | 堅持原本的使命：找到、隔離、銷毀 | 有時是盟友，但手段冷酷：為了隔離，可以犧牲整座研究站的人 |
| **典藏派** | 想研究眠系的「休眠」能力，達成長生 | 主要反派。秘密資助各地的研究計畫，等著看哪裡先「醒」 |

- **與 1 代的連結**：北緯站站長的私人研究經費，其實來自典藏派。這就是他不敢上報感染的真正原因。1 代只用文件和錄音暗示這件事，不說破。

## 4. 系列時間軸

| 年份 | 事件 | 對應作品 |
|---|---|---|
| 約 4 萬年前 | 一次暖化期結束，眠系隨著北極凍土一起進入休眠 | （背景） |
| 1957～58 | 國際地球物理年，第一批活體樣本被發現；《靜默協定》成立 | （背景） |
| **1962** | 冷戰高峰，日本北方孤島的觀測站第一次記錄到「共鳴」，協定第一次出動 | **前傳**（見 5.3） |
| 1990 年代 | 協定分裂成守門派、典藏派 | （背景，文件裡提到） |
| **2031** | 北極灰鴉島「北緯站」事件 | **1 代** |
| 2033 | 深海事件 | **2 代** |
| 2036 | 高原冰河事件，第一次有感染擴散到城市 | **4 代** |
| 2039 | 南極冰下湖，協定的總部「沉眠庫」 | **5 代** |
| 2042 | 全球同時出現「共鳴」 | **6 代** |

> 說明：時間軸是「預留的骨架」，之後可以調整。重點是每一代之間留 2～3 年的空白，讓之後能插入外傳。

## 5. 各代構想（初步，只決定方向）

### 1 代：*DEEPWAKE*／《驚蟄》（2031，北極）
- **地點**：北極灰鴉島，國際氣候研究站「北緯站」
- **病原體**：霜鳴菌（怕冷、讓宿主失明、聽覺發達、骨骼礦化共鳴）
- **玩法主題**：**聲音**
- **主角**：沈若寧，補給直升機駕駛
- **留給系列的伏筆**：
  - 站長的經費來源（典藏派）
  - 頂樓通訊室收到一則不是救援隊發出的回覆：「**原地等待。我們會去接你。**」
  - 沈若寧被感染了，但菌在她體內進入休眠，沒有發作

### 2 代：深海（2033）
- **地點**：太平洋深處的海底可燃冰（甲烷水合物）開採平台，連接一座深海研究艙
- **病原體**：在高壓無光環境中休眠的眠系分支，感染後宿主會**發光**
- **玩法主題**：**光**。怪物會被光吸引，手電筒變成最危險的工具，同時玩家要靠怪物自己發出的光看路
- **主角**：新主角；沈若寧以協助者身分出現（她身上的休眠菌讓協定對她很有興趣）

### 前傳：《驚蟄 前傳》（1962，日本北方孤島）
- **地點**：氣象觀測站兼無線電中繼站（就是原本的提案 B）
- **玩法主題**：**更重的潛行**。這一代主角是協定派來的特務，冷戰背景，敵人包括人類士兵和感染者
- **系列意義**：說明《靜默協定》的起源，第一次出現「共鳴」的紀錄
- **推出時機**：建議放在 3 代，或作為 2 代和 4 代之間的外傳。前傳比較適合在玩家已經對系列有興趣之後推出

### 4 代：高原冰河（2036）
- **地點**：亞洲高原的冰河，冰河下游有水壩、水力發電廠和一座小城
- **病原體**：隨著冰河融水擴散的分支，感染會透過**水**傳播
- **玩法主題**：**水與寒冷**。範圍第一次從「一棟建築」擴大到「一座小城的一部分」
- **系列意義**：第一次有感染擴散到人類城鎮，事件再也藏不住

### 5 代：南極冰下湖（2039）
- **地點**：南極冰層下數公里的冰下湖，協定的總部「沉眠庫」，收藏了 80 年來所有的樣本
- **玩法主題**：**選擇**。所有派系、所有倖存的角色在這裡交會
- **系列意義**：揭露眠系和地球大滅絕的關係，以及典藏派真正想做的事

### 6 代：全球共鳴（2042）
- **地點**：**台灣**。全世界的眠系同時開始「共鳴」，沈若寧回到自己的家鄉
- **系列意義**：系列的第一個大結局。從「世界盡頭」回到「我們生活的地方」，恐怖感最貼近玩家
- 6 代之後可以開啟新的篇章，或回頭做更多前傳和外傳

## 6. 重複登場的角色

| 角色 | 身分 | 系列中的弧線 |
|---|---|---|
| **沈若寧** | 1 代主角，台灣籍直升機駕駛 | 系列的「臉」。1 代倖存，但體內帶著休眠的菌。之後她既是倖存者，也是各派系想要的「活樣本」。在 2、5、6 代登場 |
| **典藏者** | 典藏派的代理人，代號，沒有真名 | 1 代只出現在通訊和文件中（「原地等待」就是他發的），2 代以後正式登場，是長線的主要反派 |
| **艾娜・科瓦契**（暫定） | 北緯站的微生物學家，1 代事件發生前就離開了研究站 | 1 代只出現在研究紀錄裡，是第一個為霜鳴菌命名的人。2 代起成為重要的盟友，後來加入守門派 |
| **守門派指揮官**（暫定） | 守門派的現場負責人 | 立場模糊的角色，有時幫主角，有時為了隔離拋棄主角 |

## 7. 讓每一代都「有關聯」的做法

1. **正史結局**：1 代有 2～3 個結局，但要事先決定哪一個是**正史結局**，之後的作品以正史結局為準（惡靈古堡系列也是這樣處理多結局）。
   - **建議的 1 代正史結局**：沈若寧在頂樓發出「隔離」訊號，北緯站被摧毀，她搭上一架不是救援隊派來的直升機離開。
2. **文件系統**：每一代都有可收集的文件和錄音，其中一部分是「系列線索」，暗示協定、眠系或下一代的地點。不看這些文件也能玩懂這一代，但會看的玩家會發現更大的故事。
3. **固定的系列識別**：
   - **共鳴聲**：每一代都會出現同一段旋律化的「共鳴」音效，作為系列的聲音商標（它在每一代的形式不同，但節奏相同）。
   - **協定的標誌**：只在文件和設施角落出現的一個簡單符號，玩家會慢慢認得。
   - **安全屋**：每一代的安全屋都有一個相同的物件（例如同一款舊型保溫瓶或收音機），讓玩家一眼就感到安心。
4. **每一代開頭不需要看過前作**：主角換人或重新介紹，前作的事件只透過文件和對話帶過。
