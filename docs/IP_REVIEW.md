# AFTERSIGNAL《迴頻》：遊戲總監／投資人評估與 IP 企劃

> 版本：2026-11-26（改版前名稱 DEEPWAKE《驚蟄》）
> 用途：用投資人的角度看「這款遊戲能不能賣、能不能變成一個 IP」，以及這次改版做了什麼、還缺什麼。

試玩範圍：主線（南岸 → 研究站 → 二樓 → 地下室 → 機庫 Boss → 天線塔 → 北港 → 守門一號 → 鑽探井 → 結局）、生存模式「長夜」、手機 UI、觸控操作。

| 項目 | 分數（10） | 評語 |
|---|---|---|
| 操作流暢度 | 7.5 | 朝向＋自動鎖定、閃躲、近戰連段、浮動搖桿都對手機友善；無縫地圖讓探索不再一直讀取 |
| 潛行系統 | 8 | 「聲音」當核心玩法很有特色（鳴骨者的喀喀聲、腳步聲、無線電通報），是最強的賣點 |
| 劇情與過場 | 6 | 過場用遊戲畫面演出、有頭像，品質不錯；但開場太慢，第一個鉤子出現得太晚 |
| 世界觀 | 5 | 「遠古微生物＋極地研究站」和《突變第三型》《最後生還者》等太接近，**很難在一句話裡講出差異** |
| 美術辨識度 | 6 | 3D 算圖的像素角色很一致；但整體色調偏灰藍，截圖放在商店頁不夠搶眼 |
| 系統深度 | 8 | 寒冷、電力、裝備、無線電調頻、圖鑑、生存模式，份量足夠撐一款買斷制遊戲 |
| IP 延伸性 | 5 | 名稱「驚蟄」對海外不好念；病原體設定讓故事只能停在「現在」，難以做成系列影視 |

**結論**：遊戲本體（玩法、系統）已經有商業水準，**真正的問題在包裝**：題材同質、沒有一眼記得住的視覺、沒有能延伸成系列的「大概念」。這次改版集中處理這三件事。

## 2. 重新定位：AFTERSIGNAL《迴頻》

### 2.1 一句話（logline）
> **1962 年，北極的監聽站從冰層底下收到一段廣播——它來自 2099 年。聽得夠久的人，會被它改寫。**

### 2.2 為什麼這樣改
- **不是細菌、不是病毒**：怪物是被「訊號」覆寫的人（回聲體）。玩法完全不用改——它們本來就是聽聲音的，現在連設定都和「聲音」是同一件事。
- **過去／現在／未來**：同一個頻率 126.05 MHz 串起三個時代。
  - **1962（過去）**：冷戰監聽站「燈籠」第一次收到訊號，《靜默協定》因此成立。泛黃的老底片色調。
  - **2026（現在）**：主線。補給飛行員沈若寧降落在灰鴉島。
  - **2099（未來）**：訊號的來源——一座所有人共用同一個聲音的城市「合唱」。賽博龐克的霓虹幻象。
- **80 年代＋霓虹＋賽博龐克**：研究站在 1985 年改建過，留下霓虹招牌、交誼廳的大型電玩、盤式錄音機和錄音帶；守門派用全息投影；未來是青／洋紅的霓虹城市。
- **名稱**：*AFTERSIGNAL*（訊號之後／餘訊）自創字、好搜尋；中文《迴頻》＝「回來的頻率」，同時有「迴響」的恐怖感。快速搜尋沒找到同名遊戲（正式定案前仍要做商標檢索）。

### 2.3 賣點（商店頁、預告片可以直接用）
1. **用耳朵玩的潛行恐怖**：怪物看不見，但什麼都聽得到。
2. **同一個頻率，三個時代**：走進 1962 年的錄音帶記憶，聽見 2099 年的城市。
3. **80 年代霓虹 × 冷戰 × 賽博龐克**的像素美術，截圖一眼就認得。
4. **無縫地圖**：沒有讀取畫面的研究站、港口、軍事基地。
5. **為手機設計**：單手搖桿、自動鎖定、聲音提示、輔助模式、省電模式；買斷制，沒有廣告、沒有內購。
6. **三個結局**，每個結局決定 2099 年的未來會不會發生。

## 4. IP 延伸計畫

### 4.1 為什麼這個設定適合做成 IP
- **一個頻率＝一個入口**：任何時代、任何地點，只要有人收到 126.05，就能開一個新故事。不需要每次重新解釋怪物從哪來。
- **時代可以換**：1962 冷戰諜報、1985 霓虹年代、2026 現在、2099 賽博龐克——每個時代都是一種類型片。
- **聲音是商標**：126.05 的旋律、盤式錄音機的轉動聲、霓虹燈管的嗡嗡聲，都能做成系列的聲音識別。

### 4.2 影視
- **電影**（約 100 分鐘）：本篇。封閉空間＋暴風雪＋「看不見的怪物靠聽」，適合中低預算的驚悚片。冷開場用 1962 年的黑白／泛黃畫面，最後一幕跳到 2099。
- **影集**（每季一個時代）：第一季「燈籠 1962」（冷戰監聽站、靜默協定成立）、第二季「北緯 1985」（霓虹年代的研究站派對之夜）、第三季「灰鴉 2026」（本篇）、第四季「合唱 2099」。

### 4.3 漫畫／小說
- **前傳漫畫《燈籠站》**：佐藤下士的視角，1962 年 3 月的那一週。遊戲裡的日誌、少校的命令、給女兒美佳的信都是現成素材。
- **選集《126.05》**：每一話是世界上某個人在某一年收到這個頻率。適合邀請不同畫家，各自畫一個時代。

### 4.4 周邊
- 霓虹燈招牌（NORTH LATITUDE、ON AIR、REC ROOM）、壓克力燈。
- **原聲帶**：合成器風格，出黑膠／卡帶版（遊戲裡就有錄音帶，周邊和遊戲互相呼應）。
- 盤式錄音機造型的藍牙喇叭、「126.05」收音機造型夜燈。
- 靜默協定徽章、守門派臂章、北緯站工作服外套。
- **ARG（實境解謎）**：上市前在網站放出「126.05」的錄音，隱藏 1962 年的文件，引導玩家到 Steam 頁面。

### 4.5 資料片（本篇＋資料片模式不變）
- **1962：燈籠**（大型）：完整的冷戰潛行章節，主角佐藤。本次已做了一段可玩的記憶當作試作。
- **1985：霓虹之夜**（中型）：研究站改建落成派對當晚，訊號第二次出現。霓虹、大型電玩、錄影帶的年代。
- **2099：合唱**（大型）：走進訊號的來源，賽博龐克城市裡的潛行。

## 5. 這次改版做了什麼（已完成）

| 類別 | 內容 |
|---|---|
| 名稱 | DEEPWAKE《驚蟄》→ **AFTERSIGNAL《迴頻》**；標題畫面改成 80 年代合成波風格（霓虹網格、條紋太陽、天線塔、收訊不良錯位） |
| 世界觀 | 怪物＝被訊號覆寫的「回聲體」；感染值＝雜訊值；孢子區＝訊號霧；生化防護衣＝法拉第衣；抗菌藥劑＝抑頻針。所有文件、無線電、圖鑑、結局都改寫 |
| 開場 | 冷開場改成 1962 年的監聽站（泛黃老底片），訊號說出 2099 年的聲音，再跳到「六十四年後」 |
| 過去 | **可玩的 1962 年記憶「燈籠監聽站」**：B1 的盤式錄音機進入，避開三個士兵，到 ON AIR 錄音室播放最後一捲帶子。看完回到現在，解鎖佐藤藏的補給；支線「燈籠站，1962」 |
| 未來 | 2099 年的霓虹色調：過場裡的「合唱」、每個結局最後一句是 2099 年的未來、結局畫面換成未來色調 |
| 80 年代／霓虹 | 研究站大廳 NORTH LATITUDE、LAB、交誼廳 REC ROOM 霓虹燈和大型電玩、潔淨室、小屋 HOT COFFEE；守門一號的全息投影；霓虹燈會閃、在地上投出彩色的光 |
| 畫面後製 | 霓虹色調（暗部偏紫、亮部偏洋紅）、淡淡的 CRT 掃描線、邊緣色差；1962＝泛黃、刮痕、閃爍；2099＝青／洋紅霓虹 |
| 手機體驗 | 選項畫面（標題、暫停選單）：音樂／音效、聲音提示、輔助模式、觸控按鈕透明度、左手模式、省電模式 |
| 測試 | 自動測試 692 項全部通過（新增 1962 記憶、霓虹、時代色調、選項的測試） |

## 6. 還沒做、建議下一步（依投資報酬排序）

1. **原創合成器配樂**：現在音樂還是程式合成的暫代版。配樂是 80 年代風格的靈魂，也是周邊（黑膠、卡帶）的基礎。
2. **商店頁素材**：用新的標題畫面和霓虹場景做 Steam／App Store 截圖與 30 秒預告。
3. **再做一段記憶（1985 霓虹之夜）**：系統已經做好（盤式錄音機＋時代色調），只要加地圖和過場。
4. **配音**：至少開場和 1962 的錄音帶要有聲音（這款遊戲是「用耳朵玩」的）。
5. **iCloud／Steam 雲端存檔**、iOS 試玩章節＋一次買斷（匯出階段做）。
6. **商標檢索**：AFTERSIGNAL／迴頻（台灣、美國、歐盟、日本，第 9、41 類）。
