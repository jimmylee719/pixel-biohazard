# 遊戲設計文件（GDD）— DEEPWAKE／《驚蟄》（系列第 1 代，名稱待商標確認）

> 狀態：草稿 v0.4（地圖改為半開放結構）；v0.3，世界觀與四項細節已確認；系列名稱候選見 [SERIES_BIBLE.md](SERIES_BIBLE.md)
> 系列長線設定（時間軸、組織、各代構想）一律以 SERIES_BIBLE.md 為準

---

## 1. 一句話介紹

在一棟彼此連通的封閉建築裡，你的子彈永遠不夠用。每遇到一個怪物，你都得當下決定要開槍、躲起來，還是繞路，活下來靠的是判斷，不是火力。

---

## 2. 設計支柱

1. **每顆子彈都要猶豫**：資源刻意設計成不夠清光所有敵人，開槍一定是取捨。
2. **看不見的比看得見的可怕**：視線遮蔽和黑暗是主要的恐怖手法，玩家永遠只看得到自己視野內的東西。
3. **聲音是雙面刃**：玩家靠聲音判斷敵人位置，敵人也靠聲音找到玩家；跑步、開槍、開門都要付出代價。
4. **建築本身就是謎題**：同一棟樓要來回走好幾次，每拿到一把鑰匙、打開一條捷徑，地圖就會「重新長出來」。

---

## 3. 核心循環

### 短循環（每 1～3 分鐘）
1. 進入新區域，先**觀察**：聽聲音、用手電筒照路、看敵人巡邏路線。
2. **判斷**：這隻怪要打、要躲，還是繞路？
3. **行動**：潛行通過、引開注意、或花彈藥解決。
4. **收穫**：撿到物資、線索、鑰匙道具。

### 中循環（每 10～20 分鐘）
1. 遇到上鎖的門或機關 → 找到對應的鑰匙或解謎道具。
2. 開啟新區域或**捷徑**，讓往返安全屋的路變短。
3. 回到**安全屋**整理物品欄、存檔、把用不到的東西放進儲物箱。
4. 帶著精簡過的裝備再出發。

### 長循環（整個流程，約 2～3 小時）
- 共 4 個區域（見第 8 節），每個區域結尾解開一個主要機關，中段和最後各有一場 Boss 戰。
- 隨著流程推進，敵人配置會改變（已清空的走廊可能出現新的敵人），強迫玩家重新評估路線。

## 4. 操作方式

### 原則
- **所有輸入一律透過 InputMap 動作名稱**，遊戲邏輯不直接讀取任何按鍵。之後加觸控和手把只要新增對應，不用改程式。
- **不設計需要滑鼠精準瞄準的玩法**。瞄準採「朝向＋自動鎖定」：舉槍時會鎖定面前扇形範圍內最近的敵人，可以切換目標。這樣鍵盤、手把、觸控都能玩。
- 移動採 8 方向（類比搖桿則為任意方向），鏡頭固定不旋轉，「往上」永遠是畫面上方。

### InputMap 動作與鍵盤預設

| 動作名稱 | 功能 | 鍵盤預設 | 備註 |
|---|---|---|---|
| `move_up` / `move_down` / `move_left` / `move_right` | 移動 | W / S / A / D（方向鍵也可） | |
| `run` | 奔跑（按住） | Shift | 會發出腳步聲 |
| `sneak` | 潛行（切換） | C | 慢速、幾乎無聲 |
| `aim` | 舉槍（按住） | 滑鼠右鍵 / K | 舉槍時不能移動，可原地轉向 |
| `fire` | 開火 / 揮擊 | 滑鼠左鍵 / J | 只在 `aim` 時有效 |
| `switch_target` | 切換鎖定目標 | Q | |
| `reload` | 裝填 | R | |
| `interact` | 調查 / 撿取 / 開門 / 躲藏 | E | |
| `flashlight` | 手電筒開關 | F | |
| `throw` | 投擲誘餌道具 | G | |
| `inventory` | 物品欄 | Tab | |
| `map` | 地圖 | M | |
| `pause` | 暫停選單 | Esc | |
| `ui_accept` / `ui_cancel` | 選單確認 / 取消 | Enter / Esc | 使用 Godot 內建 UI 動作 |

### 未來觸控版構想（iOS、手機網頁）
- **左半螢幕**：浮動虛擬搖桿，輕推是潛行速度，推到底是走路；奔跑另設一個按鈕或「推到底並停留」。
- **右半螢幕**：情境按鈕群
  - 大按鈕：`interact`（附近沒有可互動物件時隱藏）
  - 舉槍按鈕：按住舉槍，舉槍時旁邊出現「開火」和「切換目標」按鈕
  - 小按鈕：手電筒、投擲
- 物品欄、地圖、暫停放在畫面上方角落。
- 因為瞄準是自動鎖定，觸控版不需要拖曳瞄準。
- 按鈕的大小和位置之後要做可調整設定。

## 5. 鏡頭

### 平常：高角度俯視＋跟隨
- 2D 俯視（美術採略帶 3/4 視角的俯視，看得到牆面上半部和角色的臉）。
- 鏡頭跟著主角，但有**前視偏移**：鏡頭會稍微往主角面向的方向推，讓前方看得比後方多，後方的不安感因此留著。
- **死區**：主角在畫面中央一小塊範圍內移動時鏡頭不動，避免畫面一直晃。
- **房間邊界限制**：鏡頭不會照到建築外的空白；小房間時鏡頭直接固定在房間中央。
- 鏡頭位置對齊整數像素，避免像素抖動。

### 特殊鏡頭（切換時機）
| 情境 | 鏡頭表現 |
|---|---|
| **Boss 戰** | 鏡頭拉遠或改成固定構圖，看得到整個戰場；部分 Boss 戰切換到不同的視角圖層（例如側面剖面），讓戰鬥「看起來不一樣」 |
| **躲藏中** | 鏡頭鎖在躲藏點，畫面周圍加暗角，只看得到有限範圍，聽聲音判斷敵人位置 |
| **劇情與發現** | 短暫拉近或平移到重要物件（例如門鎖、屍體、怪物第一次出現） |
| **驚嚇點** | 少量使用：鏡頭稍微延遲跟隨，或突然晃動 |
| **長走廊 / 大廳** | 固定構圖，讓主角從畫面一端走到另一端，製造距離感 |

技術備註：以 Camera2D 為主，特殊鏡頭用「鏡頭區域觸發器」切換參數（縮放、偏移、固定點、限制範圍），並平滑過渡。縮放只用整數倍或預先設計好的倍率，維持像素清晰。

## 6. 潛行系統

### 6.1 敵人的感知
**視覺**
- 每個敵人有**扇形視野**（角度、距離依敵人種類不同）。
- 視線會被牆壁、櫃子等障礙物擋住（射線檢查）。
- **光線影響**：主角在暗處時，敵人的有效視距大幅縮短；**開著手電筒的主角在暗處反而非常顯眼**。手電筒的光錐照到敵人時，敵人會立刻起疑。
- 主角進入視野後不會馬上被發現，而是累積「察覺值」，距離越近、越亮、動作越大，累積越快。

**聽覺**
- 玩家的行為會產生**聲音事件**，每個事件有一個半徑：

| 行為 | 聲音半徑（暫定，單位：格） |
|---|---|
| 潛行 | 0～1 |
| 走路 | 2 |
| 奔跑 | 6 |
| 開門 / 關門 | 4 |
| 踩到碎玻璃、鐵板等地面 | 5 |
| 開槍 | 12（整個區域） |
| 投擲誘餌落地 | 6（在落點） |

- 敵人在半徑內就會「聽到」，往聲源移動調查。牆壁會讓半徑打折扣。

### 6.2 敵人狀態

```
未察覺 ──(看到或聽到可疑)──► 起疑 ──(察覺值滿)──► 警戒（追擊）
   ▲                           │                         │
   │                      (查不到東西)                (追丟主角)
   │                           ▼                         ▼
   └──────(搜索結束)────────── 搜索 ◄───────────────────────┘
```

| 狀態 | 行為 | 給玩家的提示 |
|---|---|---|
| **未察覺** | 照固定路線巡邏或待在原地 | 無 |
| **起疑** | 停下、轉向可疑方向，慢慢走到最後聽到或看到的位置 | 頭上出現小問號、特定音效 |
| **警戒** | 全速追擊，會開門、會跟著聲音追 | 頭上出現驚嘆號、音樂改變 |
| **搜索** | 在最後看到主角的地方附近繞圈搜索一段時間 | 問號閃爍 |

- 搜索結束後回到巡邏，但**有記憶**：起疑過的敵人之後視野會稍微變大一段時間。

### 6.3 躲藏與迴避
- **躲藏點**：櫃子、床底、桌下、深色角落。按 `interact` 進入。
  - 敵人沒親眼看到你躲進去，就不會發現。
  - 被看到躲進去，敵人會直接把你拖出來（受傷）。
- **黑暗**：關掉手電筒站在暗處、不動，本身就是一種躲藏，但玩家自己也看不清楚。
- **誘餌**：撿到的空瓶、零件可以丟出去製造聲音，把敵人引開。
- **繞路**：每個區域至少有兩條路線，一條快但有敵人，一條慢但安全，或需要先解開捷徑。
- **門**：關上的門擋視線，也會讓聲音打折扣；有些敵人不會開門。

## 7. 戰鬥與資源

### 原則
- 整個流程的總彈藥量，**大約只夠殺掉 50～60% 的敵人**。
- 打倒敵人**不會掉落物資**，避免「殺越多拿越多」，殺怪永遠是純支出。
- 正面硬打一定會受傷；戰鬥的意義是「清出一條常走的路」，不是賺經驗值。

### 武器（共 4 種，名稱依世界觀決定）
| 類型 | 特性 | 用途 |
|---|---|---|
| **近戰武器** | 無限使用，傷害低，有耐久度或硬直 | 處理落單的弱敵、打破障礙物 |
| **手槍類** | 彈藥最常見，命中穩定 | 主力 |
| **散彈類** | 近距離擊退、高傷害，彈藥很少 | 緊急脫身、Boss |
| **特殊武器** | 流程後半取得，對特定敵人特別有效（例如火焰、強光） | 對付特定怪物和最終 Boss |

- 舉槍時移動停止，準心會在一小段時間內「收束」，等越久越準、傷害越高（爆頭或要害），讓「在危險中多等一秒」成為取捨。
- 裝填需要時間，會被打斷。

### 補血
- **小型回復**：回復少量，最常見。
- **大型回復**：回復大量，稀少。
- **組合**：兩個小型回復可以在物品欄裡組合成較好的回復（組合規則要原創，依世界觀決定材料）。
- 生命值不顯示數字，用角色動作（走路變慢、扶牆）和畫面邊緣的狀態來呈現。

### 物品欄
- **起始 6 格**，流程中可擴充兩次，最多 **10 格**。
- 武器、彈藥、回復道具、誘餌都佔格子；彈藥同種類可以疊加。
- **鑰匙和劇情道具不佔格子**，放在獨立的「鑰匙圈」，用完會自動標示可以丟棄。這樣可以減少來回跑腿的挫折，把壓力留給資源管理。
- **安全屋儲物箱**：每個安全屋的儲物箱共用同一個空間。

### 存檔
- 只能在**安全屋**存檔，全遊戲約 4～5 間安全屋。
- 普通難度：存檔無限制。
- 困難難度：存檔需要消耗道具。
- 安全屋內不會有敵人進入，有專屬的安心配樂。

## 8. 地圖結構（v0.4 修訂：半開放的灰鴉島）

> 修訂原因：使用者希望有一定的自由度，參考 MGS3／MGSV「有主線、也能接支線」的結構；地圖互相連通，但不要一直找鑰匙解鎖。

### 8.1 判斷：要學 MGS 的哪一部分
| 參考 | 要學的 | 不學的 |
|---|---|---|
| **MGS3** | 一塊一塊相連的區域、每塊都有多種通過方式、可以自由回頭 | — |
| **MGSV** | 主任務＋支線任務的結構、任務是「目標」不是「路線」、支線獎勵讓主線更好打 | 大型開放世界、車輛、基地經營（規模太大，像素生存恐怖撐不起來，也會稀釋恐怖感） |
| **原本的惡靈古堡式設計** | 安全屋、資源稀少、捷徑、建築本身是謎題 | 一路找彩色鑰匙、鑰匙開一扇門就丟掉的流程 |

**結論：「小島＋高密度」的半開放結構。** 地圖不大，但每一塊都有內容；自由度來自「路線、順序、做法」，不是來自「面積」。

### 8.2 灰鴉島的區域

```
                       【天線塔】← 終章
                           │（主線 3 解鎖）
   【氣象小屋群】── 【北緯站主樓】── 【機庫】← 中期 Boss
        │          (地下／一樓／二樓)      │
        │                 │               │
   【碼頭與燃料庫】── 【南岸雪原】──────────┘
                     （起點：墜機點）
                           ↓（主線最後）
                       【鑽探井】← 最終 Boss
```

| 區域 | 類型 | 內容 |
|---|---|---|
| **南岸雪原** | 戶外、起點 | 直升機墜落處、研究站正門與貨運入口；暴風雪中視線極差 |
| **北緯站主樓** | 室內、核心 | 原本 GDD 的「一棟建築」：地下（樣本庫）、一樓（交誼廳、實驗室、醫務室）、二樓（宿舍、站長室） |
| **機庫** | 室內 | 中期 Boss（北極熊）；修好之後可以用雪地車在區域間快速移動（只是捷徑，不是自由駕駛） |
| **氣象小屋群** | 戶外＋小屋 | 支線集中地；幾間分散的小屋，各自有故事 |
| **碼頭與燃料庫** | 戶外＋倉庫 | 支線；燃料是讓發電機運作的關鍵資源 |
| **天線塔** | 戶外＋垂直 | 主線終點之一：對外發出訊號 |
| **鑽探井** | 地下 | 最終 Boss |

- 大部分區域**一開始就能走到**，只是有些地方非常危險，或需要先準備好（見 8.3）。
- 室內與戶外交錯：室內是潛行、躲藏；戶外是暴風雪中的移動與能見度管理。
- 每個區域的入口不只一個（正門、側門、通風管、窗戶、屋頂），玩家選擇從哪裡進去。

### 8.3 用「軟性門檻」取代彩色鑰匙
| 門檻 | 怎麼運作 | 為什麼比鑰匙好 |
|---|---|---|
| **寒冷（體溫）** | 戶外會持續失溫；距離越遠的區域越需要準備（保暖裝備、暖氣站、熱飲）。可以硬闖，但很危險 | 玩家自己決定「現在準備好了沒」 |
| **電力** | 發電機恢復後：電動門、電梯、暖氣、監視器可用。電力也是溫度機制的開關 | 一個主線目標改變整張地圖的狀態 |
| **工具** | 鐵撬（木板封住的門窗）、冰爪（結冰的坡道）、剪線鉗（圍欄）。一個工具在全島各處都能用 | 拿到工具會讓玩家想起「那個地方現在可以進去了」，而且不會用完就丟 |
| **權限卡等級** | 只有一張卡，靠主線升級（1 → 2 → 3），取代一堆不同的鑰匙 | 減少翻物品欄找鑰匙的挫折 |
| **敵人密度** | 路本身是通的，只是很危險 | 這就是潛行遊戲的「門」 |

- **門一旦打開就永久打開**，自然形成捷徑。
- 保留少量「特定謎題」（密碼、配電盤順序），但線索都在附近，不需要跨半張地圖找鑰匙。

### 8.4 主線與支線
**主線（Main Ops）**：5 個，部分可以自由排順序。
1. **進入研究站**（教學）：從貨運入口潛入主樓。
2. **恢復電力**：到燃料庫取得燃料、到地下發電室啟動發電機。
3. **找到站長的研究紀錄**：二樓站長室，取得權限卡等級 2。
   - 2 和 3 可以任意順序。
4. **修好機庫的雪地車／擊退中期 Boss**：打開通往天線塔和鑽探井的路。
5. **在天線塔發出訊號 → 進入鑽探井**：終章與結局分歧。

**支線（Side Ops）**：約 10～12 個，透過**安全屋的無線電**接到（倖存者求救、遠端的微生物學家艾娜的委託、研究站的自動警報）。
| 類型 | 例子 | 獎勵 |
|---|---|---|
| 救援 | 氣象小屋裡受困的倖存者，護送回安全屋 | 倖存者在安全屋提供服務（例如幫你組合藥劑） |
| 回收 | 取回某間實驗室的樣本或硬碟 | 抗菌藥劑配方、劇情線索 |
| 修復 | 修好一座戶外暖氣站 | 新的「暖區」（戶外中繼點），擴大行動範圍 |
| 情報 | 找到失蹤隊員的錄音 | 地圖上顯示某區域的敵人巡邏路線 |
| 處理 | 引開或解決盤踞某處的感染者（不一定要殺） | 打開一條捷徑 |
| 補給 | 找到空投補給箱 | 彈藥、物品欄擴充 |

- **支線不是必要的，但能讓主線好打很多**：只走主線的玩家資源會更拮据。這正好強化「每顆子彈都要猶豫」。
- 物資**不會重生**，支線的獎勵有限、不能刷。
- 任務是「目標」不是「路線」：只告訴你要去哪、做什麼，怎麼過去由你決定。

### 8.5 流程長度
- 只走主線：約 2～3 小時（和原本的規劃一樣）。
- 加上全部支線：約 4～5 小時。

### 8.6 規模控制（避免做不完）
- 區域數控制在 7 個，戶外區域用同一套雪地圖格和少量道具組合。
- 支線用**任務模板**（救援、回收、修復……）＋資料設定製作，不為每個支線寫新系統。
- 敵人仍然是 3 種一般敵人（加上變體）＋ 2 個 Boss。

### 8.7 技術方向（給實作用）
- **區域 = 獨立場景**，經由門、通道切換，避免一次載入整座島（網頁版、手機效能）。
- **世界狀態**（WorldState）記錄：撿過的物品、打開的門、電力和暖氣狀態、任務進度、主角物品，切換區域、存檔都靠它。
- **任務系統**用資料定義：目標類型（到達某處、和某物件互動、取得某物品），由遊戲事件推進。

### 8.8 地圖畫面
- 拿到區域地圖後，地圖顯示該區域的房間與出入口。
- 房間依狀態用不同方式標示：「沒去過」「還有東西沒拿」「已經搜刮完」。
- 任務目標顯示在地圖上，但**不顯示路線**。

## 9. 恐怖感怎麼做

### 視線遮蔽（核心技術）
- 主角只能看到「視線沒被牆擋住」的範圍，牆後、門後的區域是暗的（2D 視野遮罩 / 陰影投射）。
- 敵人在視線外就**不會被畫出來**，只能靠聲音判斷。
- 門關著的房間看不到裡面，打開門的那一刻是最緊張的時候。

### 手電筒
- 手電筒照出一道光錐，是唯一能看清遠處的方法。
- **雙面刃**：開著能看清楚，但敵人也更容易看到你。
- 電池是一種資源，但不要嚴苛到讓人煩躁（電量低時光會閃爍，提醒換電池）。
- 少數敵人怕光或被光吸引，讓手電筒變成戰術選擇。

### 聲音先於影像
- 敵人出現前，一定會先聽到聲音：腳步、拖行、呼吸、碰撞聲。
- 使用**立體聲定位**，讓玩家光聽就能判斷左右和遠近。
- 刻意安排「只有聲音、沒有怪物」的時刻，讓玩家自己嚇自己。
- 背景音樂大部分時間很安靜，用環境音（滴水、風聲、電流聲）撐場；只有警戒狀態才進入緊張配樂。

### 其他手法
- **建築會變**：回頭經過的走廊，可能多了血跡、門被打開、東西被移動。
- **安全感的落差**：安全屋做得很溫暖（光、音樂），出門那一刻更冷。
- **克制的驚嚇**：驚嚇點全遊戲控制在少數幾個，大部分恐懼來自氛圍和不確定感。
- **像素的留白**：低解析度讓玩家自己腦補細節，怪物造型保留模糊和不對稱。

## 10. 世界觀（已選定：提案 B 修改版）

> 決定：採用提案 B 的「世界盡頭的孤島＋聲音怪物」，但把怪物的成因改成**生物性**：冰封在永凍土裡的遠古菌種，因為全球暖化而解凍、擴散。
> 因為「暖化讓遠古菌種甦醒」必須發生在現代，時代從 1962 年改為**近未來 2031 年**。
> 原本的提案 A、C 移到本節最後的「未採用提案」，保留作為參考。

### 遊戲名稱
- 推薦系列名稱：英文 **DEEPWAKE**／中文 **《驚蟄》**，第 1 代不加副標題。
- 選名分析與其他候選見 [SERIES_BIBLE.md](SERIES_BIBLE.md) 第 1 節。原本的《凍鳴》、《永凍迴聲》、《解凍》太綁定北極場景，不適合當系列名稱。

---

### 10.1 時代與地點
- **時代**：2031 年 11 月，北極圈的極夜剛開始，白天只剩一兩個小時的微光。
- **地點**：北極海上一座虛構的島嶼「**灰鴉島**」。島上只有一棟建築：國際聯合氣候研究站「**北緯站**」。
  - 研究站是一棟**依山坡蓋的五層混凝土建築**，一側緊貼著正在崩落的永凍土斷崖。
  - 研究站的任務是鑽取永凍土和冰芯、監測暖化速度，經費來自多國的科學基金，**不是任何企業的設施**。
  - 冬季唯一的對外交通是每月一班的補給直升機。衛星通訊靠頂樓的天線塔。

### 10.2 發生了什麼事
1. 這幾年夏天異常炎熱，研究站旁的斷崖崩落，露出一層**四萬年前的凍土層**，裡面封著大量冰凍的史前動物遺骸。
2. 研究員從遺骸的內耳和神經組織中，分離出一種從未見過的**遠古古菌**，研究員私下叫它「**霜鳴菌**」。它在零下的環境中休眠，只要回到體溫，幾小時內就會甦醒繁殖。
3. 站長發現有研究員被感染，但沒有上報。他擔心一旦通報，整個研究計畫會被封存、經費會被收回，於是把感染者關在地下的冷藏區，想自己找出解法。
4. 一場暴風雪讓補給延誤了三週。冷藏區的電力在某天夜裡中斷，溫度回升。
5. 主角抵達時，研究站已經安靜了九天。最後一則對外通訊只有一段錄音：持續不斷、規律的「**喀、喀、喀**」聲。

**這個設定刻意避開的套路**
- 沒有製藥公司或企業陰謀：災難來自「科學研究＋一個人的隱瞞＋氣候變遷」，比較接近真實世界的風險。
- 不是真菌、不是殭屍病毒：霜鳴菌是**古菌**，感染神經和骨骼，症狀是失明、聽覺異常發達、骨骼礦化。
- 不是外星生物，也**不會複製或偽裝成人**（避開《突變第三型》*The Thing* 的南極基地＋擬態套路）。感染者外觀明顯異常，恐怖來自「聽得到但看不到」，不是「誰是怪物」。

### 10.3 霜鳴菌怎麼運作（同時是玩法規則）
| 特性 | 世界觀說明 | 對應玩法 |
|---|---|---|
| **怕冷** | 低溫時菌會進入休眠 | **溫度機制**：關掉某個區域的暖氣，那裡的感染者會變慢、反應遲鈍；但要從配電室操作，而且有些門和機關需要電力 |
| **破壞視覺、強化聽覺** | 菌偏好寄生在內耳和視神經 | 越晚期的感染者越瞎、聽覺越好，對應三種敵人的感知差異 |
| **骨骼礦化、會共鳴** | 宿主的骨骼長出結晶，能發出喀喀聲做「回聲定位」 | 敵人出現前一定會先聽到喀喀聲，「聲音先於影像」直接寫進設定裡；聽覺型敵人聽到你時會發出高頻鳴叫，**呼叫附近的同類** |
| **經由體液傳染** | 被咬、被抓傷有機會感染 | 主角被攻擊會累積「感染值」，必須用抗菌藥劑壓制（第二種回復資源，見下方） |

**新增資源（已確認）：抗菌藥劑**
- 生命值之外，主角有一條隱藏的「感染值」。被攻擊會增加，滿了就會出現症狀（視野周圍變白、聽到不存在的喀喀聲、移動變慢）。
- 抗菌藥劑可以降低感染值，跟補血道具一樣稀少、佔物品欄格子。
- 這讓「被摸到一下」也有代價，強化「能躲就躲」。

### 10.4 怪物
| 類型 | 名稱 | 外觀與行為 |
|---|---|---|
| 巡邏型 | **值班者** | 早期感染的研究站人員。眼睛混濁但還看得到一點，照著生前的工作路線巡邏（巡房、檢查儀表）。視野窄而短，但走廊很長時會看得到亮著手電筒的你。 |
| 聽覺型 | **鳴骨者** | 晚期感染者，完全失明，胸口和下顎長出結晶骨，不停發出喀喀聲做回聲定位。對聲音極敏感，聽到你會尖鳴、呼叫同類。**完全不在乎手電筒**，是「可以開燈但不能出聲」的敵人。 |
| 伏擊型 | **凍眠體** | 在冷藏區、戶外走道、結冰的房間裡，看起來像凍僵的屍體。周圍溫度回升或聽到附近有聲音就會甦醒撲上來。玩家要學會分辨「真的屍體」和「凍眠體」的細微差別。 |
| 中期 Boss | **苔原之母**（暫定） | 被感染的北極熊，被困在研究站的機庫。龐大、全盲、聽覺極好。戰鬥場地可以切換暖氣和照明，利用溫度讓牠變慢。鏡頭拉遠成固定的機庫全景。 |
| 最終 Boss | **深井** | 最早被感染的那批研究員，在地下鑽探井裡與菌落融合成一整片會共鳴的結晶體。戰鬥時鏡頭切換成**鑽探井的垂直剖面視角**，主角沿著井壁的維修梯一層層往下。 |

### 10.5 主角
- **姓名**：**沈若寧**（暫定），34 歲，台灣籍，極地補給直升機的駕駛。
  - 選擇台灣籍主角，讓「世界盡頭」的距離感更強：她離家非常非常遠，在這裡沒有任何人認識她。
  - 她不是軍人、不是特務，只受過基本的求生訓練，射擊不準，這符合「資源少、要靠判斷」的設計。
- **為什麼非進去不可**：
  1. 她開著延誤了三週的補給直升機抵達，降落時遇上暴風雪，**直升機受損、無法再起飛**。戶外是零下四十度的極夜，唯一的遮蔽處就是研究站。
  2. 頂樓的天線塔是全島唯一能對外聯絡的設備，她必須爬到頂樓才能求救。
  3. 隨著調查，她發現更大的問題：如果救援隊直接把倖存者撤離到大陸，霜鳴菌就會離開這座島。她的目標從「求救」變成「**決定要讓誰離開這座島**」。

### 10.6 結局方向（初步）
- 結局取決於主角在頂樓發出的訊息：要求救援、要求隔離、或要求摧毀研究站。
- 再加上她自己的感染值：如果最後她也被感染，她還能讓自己搭上救援直升機嗎？
- 數量控制在 2～3 個結局，不做龐大的分支。
- **正史結局**（之後的作品以此為準）：發出「隔離」訊號，北緯站被摧毀，她搭上一架不是救援隊派來的直升機離開。
- **系列伏筆**（不在 1 代說破）：
  - 站長的私人經費來自《靜默協定》的典藏派。
  - 通訊室收到一則不是救援隊發出的回覆：「原地等待。我們會去接你。」
  - 沈若寧體內的霜鳴菌進入休眠，沒有發作。

## 11. 第一個可玩原型（Prototype 0）範圍

目標：驗證「**看不見＋會被發現**」的緊張感是否成立。全部用簡單色塊，不做任何正式美術和音效。

### 要做的
| 項目 | 內容 | 驗收標準 |
|---|---|---|
| **場景** | 一個房間＋一條 L 形走廊，有幾個擋視線的障礙物（櫃子、牆角） | 可以從房間走到走廊盡頭 |
| **主角** | 色塊角色，8 方向移動，走路 / 潛行 / 奔跑三種速度 | 所有輸入都透過 InputMap 動作名稱 |
| **鏡頭** | Camera2D 跟隨，有前視偏移、死區、房間邊界限制，對齊整數像素 | 移動時畫面不抖動、不照到地圖外 |
| **視線遮蔽** | 牆後、障礙物後的區域變暗，敵人在視線外不顯示 | 躲在牆後看不到敵人 |
| **手電筒** | 光錐照亮前方，按 `flashlight` 開關 | 關掉時只看得到身邊一小圈 |
| **敵人** | 一隻色塊敵人，沿固定路線巡邏，有扇形視野（畫出來方便除錯），被牆擋住就看不到 | 走進視野會進入起疑 → 警戒並追擊；脫離後進入搜索，再回到巡邏 |
| **聲音** | 奔跑會產生聲音事件，敵人會往聲源調查 | 在牆後奔跑會讓敵人起疑 |
| **除錯顯示** | 敵人狀態文字、視野扇形、聲音半徑圓圈（可開關） | 方便調整數值 |

### 不做的
- 戰鬥、武器、物品欄、存檔、地圖、UI 美術、音效、觸控操作（但輸入架構要預留）。

### 原型要回答的問題
1. 視線遮蔽＋手電筒在 480x270 的解析度下，畫面還看得清楚嗎？
2. 敵人的視野和察覺值速度，玩家能不能讀懂、能不能預判？
3. 「躲在暗處 vs. 開手電筒」的取捨有沒有感覺？
4. Compatibility 渲染器下，視線遮蔽和光照在網頁版的效能是否足夠？

## 12. 原型進度

### Prototype 0（完成）
一個房間＋L 形走廊、主角移動、跟隨鏡頭、手電筒與視線遮蔽、一隻會巡邏且有視野的敵人。

### Prototype 1（完成，數值待實際試玩調整）
- **地圖擴大**：交誼廳（西）、實驗室（東）、走廊、貨運入口；交誼廳和實驗室之間多一條連通道，形成兩條路線。
- **置物櫃躲藏**：按 `interact` 躲進去，敵人看不到、摸不到；但躲進去的那一刻被看到，敵人會把你拖出來。躲藏時手電筒自動關、畫面四周變暗。
- **空瓶誘餌**：撿起來（最多 3 個），按 `throw` 朝面向丟出，落地的聲音會把敵人引到落點。
- **鳴骨者（聽覺型）**：全盲、手電筒對牠無效；聽覺是一般敵人的 1.6 倍；走路或奔跑經過身邊會被「震動」察覺，潛行不會；進入警戒時尖鳴，附近的同類會過來查看。牠發出的喀喀聲在畫面上以波紋表示，看不到牠也看得到波紋（之後換成立體聲音效）。
- **溫度機制**：實驗室的配電箱可以關掉交誼廳的暖氣，地板會結霜。冷的區域裡敵人移動、轉頭、察覺都變慢；但扳開關的聲音很大，會引來實驗室裡的鳴骨者。
- **出口**：交誼廳左上角，到達後這一輪結束並重來。
