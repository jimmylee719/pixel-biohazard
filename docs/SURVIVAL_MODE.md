# 生存模式「長夜」（THE LONG NIGHT）— 市場分析與設計

## 1. 市場上熱賣的「主線以外的模式」分析

| 參考作品 | 模式 | 為什麼受歡迎 | 我們可以拿來用的（不抄內容） |
|---|---|---|---|
| 惡靈古堡 4／Re:4、3、Village | 傭兵模式（Mercenaries） | 時間壓力＋連殺倍率＋S 級評價，短時間（5～10 分鐘）一局，重複挑戰分數 | **連殺倍率、評價（C～S）、每張地圖的最高紀錄** |
| 決勝時刻（殭屍模式） | 波次生存 | 一波比一波強、波與波之間喘口氣、越撐越久的「再一波就好」 | **波次、波間休息、越後面越強的敵人組合** |
| 逃離塔科夫、Hunt: Showdown、Dark and Darker | 撤離（Extraction） | 「要不要現在撤離」的風險抉擇：撐越久獎勵越高，但死了就失去大部分 | **撤離點：每 5 波可以撤離把獎勵帶走，死掉只留 30%** |
| 吸血鬼倖存者、Hades、Dead Cells | Roguelite 進度 | 每一局都帶回貨幣，解鎖新武器、新起始裝備，失敗也有收穫 | **殘響點數 → 解鎖武器、地圖、主線補給** |
| 惡靈勢力（Left 4 Dead）、Back 4 Blood、Lethal Company、GTFO | 多人合作逃生 | 2～4 人分工、互相救援、一起逃出去 | **未來雙人／四人：同樣的波次＋撤離規則，目標從「我」變成「離最近的玩家」** |
| 潛龍諜影 V、Ground Zeroes | 側任務／挑戰 | 在熟悉的地圖用不同規則重玩、潛入評價 | **潛行擊殺加分（無聲擊倒 ×1.5）** |
| 黎明死線、The Last of Us Factions | 非對稱／對戰 | 社群、長期遊玩 | （之後的資料片再考慮，先不做） |

**趨勢結論（2023～2026）**
1. **短局、可重複**：主線玩累了要能「10 分鐘玩一局」，手機（iOS）和網頁版尤其需要。
2. **每局都有帶走的東西**：Roguelite 式的永久解鎖是留存的核心，失敗也要有獎勵（降低挫折）。
3. **風險抉擇＞單純撐越久**：撤離機制讓每一局都有「要不要再賭一波」的緊張感。
4. **合作是長尾**：熱賣的恐怖遊戲幾乎都有合作模式（Lethal Company、Phasmophobia、R.E.P.O.），先把規則設計成「多人也成立」，之後再接網路。
5. **和主線互相回饋**：模式解鎖的東西要能帶回主線（但不能破壞主線的難度和恐怖感），反之主線的地圖、敵人直接成為模式的素材。

## 2. 「長夜」的規則

- **地圖**：用主線的區域（研究站一樓、氣象小屋群、北港），敵人改成波次刷出；門不能離開。
- **波次**：第 n 波敵人數 = 3 + 2n（最多 24）。前幾波是值班者、鳴骨者；越後面加入爬行者、獵犬、詠者、膨脹者；北港會混武裝人員。每 5 波是「深夜潮」（膨脹者、詠者一定出現）。
- **刷怪**：在門口和離玩家很遠、看不到的地方出現；出現後「聽到」玩家的位置，每隔幾秒重新追蹤（有壓力，但還是可以躲、可以潛行繞開）。
- **波間休息**：12 秒。玩家身邊空投補給（彈藥、急救包、汽油彈……，依波數變好）。
- **分數**：擊倒分數 × 連殺倍率（5 秒內再擊倒 +0.25 倍，最多 3 倍）；無聲擊倒（背刺、絞殺）×1.5；過波獎勵 500 × 波數；該波沒受傷 +300。
- **撤離**：每清完第 5、10、15……波，地圖入口出現撤離點（亮綠燈）。走過去按互動 = 撤離，獎勵全拿；繼續打 = 獎勵更多但風險更高。
- **死亡**：結束，只帶回 30% 的殘響點數。
- **評價**：依分數 C／B／A／S，每張地圖記錄最高分、最高波數、最佳評價。

## 3. 殘響點數與解鎖（存在 `user://profile.cfg`，和主線存檔分開）

| 解鎖 | 價格 | 效果 |
|---|---|---|
| 散彈槍、釘槍、信號槍、消防斧、獵槍 | 30～80 | 生存模式的起始裝備可以選 |
| 地圖：北港 | 60 | 新地圖（有武裝人員、無線電增援） |
| 補給：急救包 | 25 | 每局開始多一個急救包 |
| 主線補給箱 I | 50 | 主線「新遊戲」時，安全屋儲物箱裡多急救包＋手槍子彈 |
| 主線補給箱 II | 120 | 主線「新遊戲」時，儲物箱裡多一把釘槍和釘條 |

（主線獎勵只放在儲物箱、只在新遊戲時給：有幫助，但不會讓主線變簡單到不恐怖。）

## 4. 未來的雙人／四人合作（設計上已預留）

- **規則**：同樣的波次＋撤離。敵人追「最近的玩家」；倒地的隊友可以被扶起（倒地計時 30 秒）；全員倒地才結束；撤離需要所有活著的人都到撤離點。
- **模式**：合作逃生（撐到撤離）／殺戮（無限波次、分數排行）。
- **技術**：Godot 高階多人（MultiplayerAPI）；Steam 版用 Steam 大廳（GodotSteam），網頁版用 WebRTC，iOS 用 ENet＋配對伺服器。主機權威（敵人 AI、刷怪、分數都在主機算），客戶端只送輸入。
- **現在已經做好的準備**：生存模式的刷怪、追蹤、分數都寫在 `SurvivalMode` 一個節點裡，以「玩家清單」為單位計算；之後加入多個 Player 節點時，只要把清單換成所有玩家。
